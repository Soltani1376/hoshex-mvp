# Hoshex Execution Assistant V1

Flow:

Diagnosis → Today Action → Prepare execution → Copy/use artifact → Mark executed → Check-in date → Feedback → Next action

Execution routing:
- acquisition → content + CTA
- offer → offer copy
- sales_process → objection / DM reply
- focus → single-focus mini plan

MVP constraints:
- one artifact only
- no generic chat
- copy-ready output
- 1–7 day check-in window
- artifact persisted inside the current local Journey cycle
- AvalAI enrichment with deterministic rules fallback

Analytics events:
- execution_requested
- execution_generated
- execution_opened
- execution_copied
- execution_completed
